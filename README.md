# 马潇宁个人网站

马潇宁的个人主页，包含首页、关于我、项目、技能与联系方式。

## 自定义

打开 `index.html`，把里面的占位文字换成你自己的信息即可：

- 姓名与自我介绍：`#home` 与 `#about` 区块
- 邮箱：`#contact` 区块中的 `your-email@example.com`
- 项目：`#projects` 区块中的卡片

## 本地预览

```bash
npx serve .
```

## 部署到 GitHub Pages

将本文件夹内容推送到一个仓库（例如 `personal-website`）的 `main` 分支，
然后在仓库的 Settings → Pages 中选择从 `main` 分支部署即可。
